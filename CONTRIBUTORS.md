## Contributor Guidelines & Governance Rules
1. **Attribution Preservation:** New contributors must be added to this ledger upon merging significant contributions.
2. **Permanent Provenance:** The foundational attribution of the original developer (**Moataz Qasem**) must remain intact and must never be displaced, replaced, or diminished.
3. **Source Code Headers:** Every first-party source file must preserve original developer provenance headers as mandated by IGOS-DAPF.
4. **Attribution vs. Copyright:** Adding a contributor acknowledges collaborative technical input and does not alter the underlying legal copyright ownership or licensing model of the repository.
