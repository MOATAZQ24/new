# قائمة مراجعة التسليم ودليل التشغيل الإنتاجي — Handover Checklist
## Investor Gate OS 3.0 Operational & Administration Runbook

يوفر هذا الدليل الخطوات والإجراءات المعتمدة لإدارة وتشغيل واستضافة نظام Investor Gate OS 3.0 في البيئة الإنتاجية.

---

### 1. بيانات الدخول الإدارية المعتمدة (Initial Super Admin Setup)
- **رابط تسجيل الدخول:** `http://localhost:3000/login` (أو النطاق المعتمد للمنشأة)
- **اسم المستخدم الرئيسي:** `admin`
- **بيانات الاعتماد الأولية:** تُسلم عبر القناة الآمنة المعتمدة (أو يتم تعيينها عند أول إطلاق عبر موجه النظام / متغيرات البيئة). تم تفعيل خاصية إلزام تغيير كلمة المرور (`must_change_password=True`) لضمان عدم وجود كلمات مرور مكشوفة في المستندات.
- **الدور والصلاحيات:** مدير النظام الشامل (Super Admin) لكافة منشآت وفروع المجموعة.
- **التوصية الأمنية:** يُوصى بتغيير كلمة مرور الحساب الإداري فور استلام النظام عبر صفحة الإعدادات الشخصية.

---

### 2. إجراءات بدء التشغيل والخدمات الخلفية (Service Startup Runbook)
- **تشغيل خادم الواجهة الخلفية (Backend - FastAPI):**
  ```powershell
  Set-Location backend
  .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
  ```
- **تشغيل خادم الواجهة الأمامية (Frontend - Next.js):**
  ```powershell
  Set-Location frontend
  npm.cmd run dev -- -p 3000 -H 0.0.0.0
  ```
- **التشغيل الإنتاجي الموحد عبر Docker Compose:**
  ```bash
  docker compose -f docker-compose.yml up -d
  ```

---

### 3. سياسة النسخ الاحتياطي والاستعادة الدورية (Backup & Disaster Recovery Procedures)
- **إنشاء نسخة احتياطية فورية (Manual Backup):**
  ```bash
  bash scripts/backup.sh
  ```
  يقوم السكربت بحفظ حزمة مضغوطة تشمل قاعدة البيانات (PostgreSQL أو SQLite)، الملفات المرفوعة، ولقطة التكوين مع تشفير وحفظ في مسار `./backups`.
- **استعادة النظام من النسخة الاحتياطية (System Restore):**
  ```bash
  bash scripts/restore.sh ./backups/itops_backup_YYYYMMDD_HHMMSS.tar.gz
  ```
- **التحقق من سلامة البيانات المستعادة:**
  - التأكد من مطابقة أعداد الموظفين والأصول وسجلات التدقيق عبر مسار `/api/v1/health` ومسار لوحة المتابعة.

---

### 4. إدارة المستخدمين وتأهيل الموظفين (User Onboarding Procedures)
1. الدخول إلى صفحة الموظفين (`/employees`).
2. النقر على زر **"إضافة موظف"** لفتح النموذج المؤسسي.
3. إدخال الرقم الوظيفي، الاسم الثلاثي، والبريد الإلكتروني، وتحديد الفرع الأساسي والقسم.
4. تفعيل خيار **"إنشاء حساب دخول للنظام لهذا الموظف"**.
5. اختيار دور الصلاحيات المناسب من بين الأدوار الأربعة المعتمدة:
   - **موظف (Employee):** خدمة ذاتية للعهد والتذاكر الشخصية.
   - **فني دعم تقني (IT Technician):** معالجة التذاكر وتحديث الأصول.
   - **مدير تقنية معلومات (IT Manager):** إدارة الأصول والاعتمادات.
   - **مدير منشأة (Company Admin):** إدارة كاملة للشركة وفروعها.
6. حفظ الموظف واستخدام زر **"نسخ بيانات الدخول"** لتسليم اسم المستخدم وكلمة المرور المؤقتة بأمان.

---

### 5. حوكمة إنهاء الخدمة واسترجاع العهد (Offboarding & Deletion Safeguards)
1. التوجه لصفحة العهد (`/custody`) والتحقق من ذمة الموظف وتأكيد استرجاع كافة الأجهزة.
2. التوجه لصفحة الموظف والنقر على زر **"أرشفة الموظف"**.
3. يؤكد النظام حظر الحذف في حال وجود عهد معلقة، ويتيح الأرشفة الآمنة التي تحافظ على التذاكر وسجلات التدقيق التاريخية.
4. يمكن استعادة الموظف المؤرشف في أي وقت بنقرة واحدة عبر تبويب **"عرض الأرشيف"**.
