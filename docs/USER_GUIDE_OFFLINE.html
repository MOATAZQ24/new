الدليل التشغيلي والإداري — Investor Gate OS

نظام ذاتي الاستضافة لإدارة عمليات تقنية المعلومات والأصول والمهام متعددة الشركات.

1. التثبيت النظيف والتهيئة الأولية (Clean Install & First-Run Setup)

  1. تأكد من تشغيل Docker Desktop أو بيئة الخادم وتوليد مفاتيح SECRET_KEY و DB_PASSWORD عشوائياً.
  2. شغّل التهيئة الهيكلية النظيفة عبر python seed_data.py --clean-init لإنشاء الأدوار الستة والشركات المعتمدة والفروع الخمسة (مخرج 17، مخرج 18، العليا، الدمام، جدة) دون أي بيانات تجريبية أو كلمات مرور افتراضية.
  3. افتح المتصفح على /setup لقبول الترخيص وإنشاء حساب مدير النظام الأول (كلمة مرور قوية لا تقل عن 12 خانة).
  4. بعد الإنشاء، يُغلق مسار التهيئة تلقائياً ويُوجّه المستخدم إلى /login.

2. الوحدات التسع المعتمدة (Approved Modules)

  • لوحة المتابعة (Dashboard): مؤشرات الأداء الفورية والإجراءات السريعة والرسوم البيانية.
  • الشركات والفروع (Companies & Branches): شجرة الشركات والفروع الخمسة المعتمدة والأقسام.
  • الموظفون (Employees): ملف الموظف الشامل 360° والربط مع Telegram والأصول والاشتراكات.
  • الأصول والعهد (Assets & Custody): تسجيل الأجهزة، تسليم واسترجاع العهد، ورموز QR.
  • الاشتراكات (Subscriptions): إدارة التراخيص، توزيع المقاعد (Seats)، وتنبيهات التجديد.
  • مكتب المساعدة (Help Desk): تذاكر الدعم الفني، SLA، وتحويل التذكرة لمهمة.
  • المهام والمواعيد (Tasks & Deadlines): إسناد المهام، قبول التنفيذ، المراجعة والاعتماد.
  • التقارير (Reports): تقارير الأصول والعهد والتذاكر والمهام بصيغ Excel/CSV و PDF.
  • الإعدادات (Settings): معرض الهويات البصرية (6 سمات × فاتح/داكن/تلقائي)، التكاملات، والنسخ الاحتياطي DR.

3. الترقية الآمنة والنسخ الاحتياطي (Safe Upgrade & Disaster Recovery)

لا تقوم عمليات الترقية أو الإصلاح بحذف قاعدة البيانات أبداً. يتم التحقق من وجود بيانات سابقة، وإنشاء نسخة احتياطية متحققة بـ SHA-256 قبل تشغيل أي ترقية متوافقة (Alembic Migrations).
